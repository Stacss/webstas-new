## Слабые места старого сайта

- Универсальный оффер без чёткого отличия от веб-студий.
- Смешение личного бренда и множественного «мы».
- Одинаковые title/description на страницах кейсов; отсутствуют canonical, Open Graph, Schema.org, sitemap.xml и robots.txt.
- Английский `lang`, хотя основной контент русский; неработающие/неполные переключатели языков.
- Тяжёлый стек Bootstrap + jQuery + AOS + Swiper + несколько наборов иконок ради небольшого лендинга.
- Формы без видимого отдельного согласия, anti-spam и публичной политики ПДн.
- Подписка на новости без описанной логики и согласия.
- Неясные формулировки, опечатки, отсутствие процесса и границ результата.

## Целевая аудитория

1. Малый и средний бизнес Костромы, которому нужен сайт услуг, лендинг или корпоративный сайт.
2. Владельцы работающих PHP/Laravel-проектов, которым нужна точечная доработка.
3. Магазины автозапчастей, которым нужны каталог, личный кабинет, интеграции и автоматизация на базе SPART или доработка Docpart.
4. Компании по России, которым удобен прямой удалённый контакт с разработчиком.

## Кластеры запросов

- Коммерческие локальные: создание сайта Кострома, разработка сайтов Кострома, заказать лендинг Кострома, корпоративный сайт Кострома.
- Экспертные: разработка на Laravel, доработка Laravel сайта, разработка веб-сервисов.
- Узкие: разработка магазина автозапчастей, автоматизация магазина автозапчастей, платформа SPART, доработка Docpart, Telegram бот для Docpart, интеграция сайта с Telegram.
- Технические: оптимизация скорости сайта, Core Web Vitals, технический SEO-аудит.

Создана одна содержательная локальная страница Костромы. Массовые страницы по городам не создавались: без фактического присутствия и уникального содержания они были бы дорвеями.
